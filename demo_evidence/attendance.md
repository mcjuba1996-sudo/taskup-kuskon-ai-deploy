# Разбор посещаемости: синтетический пример

**Демо-артефакт подготовлен командой Kuskon AI с помощью Codex.** Это общий тестовый материал для нескольких вымышленных профилей, а не работа конкретного подростка. Данные, причины и оценки в приложении придуманы для проверки сценария.

**Задача:** воспроизводимо посчитать посещаемость, показать три указанных участниками причины пропусков и предложить проверяемое улучшение. Исходник — `attendance.csv`; расчёт — `analyze_attendance.py`, только стандартная библиотека Python 3.11+.

```bash
python demo_evidence/analyze_attendance.py
```

## Результат

6 вымышленных участников × 4 занятия = **24 события посещения**. Присутствий — **17**, пропусков — **7**. Посещаемость: `17 / 24 × 100 = 70,83%`. Единица анализа — событие посещения, не число уникальных детей.

**График 1. Присутствия по занятиям.** Один `#` — одно присутствие; на каждом занятии ожидалось 6 участников.

```text
DEMO-01  #####  5/6  83,33%
DEMO-02  ####   4/6  66,67%
DEMO-03  #####  5/6  83,33%
DEMO-04  ###    3/6  50,00%
```

**График 2. Указанные причины пропусков.** Один `#` — один пропуск; доли рассчитаны от 7 пропусков, а не 24 событий.

```text
Самочувствие      ###  3/7  42,86%
Транспорт         ##   2/7  28,57%
Другое занятие    ##   2/7  28,57%
```

Это **самоотчёты в синтетической таблице**, не доказанные причины оттока. Нельзя по четырём занятиям утверждать, что участники ушли навсегда, или что перенос времени повысит посещаемость. Повторные события одного участника не являются независимыми наблюдениями.

## Предложение и проверка

Гипотеза: альтернативное время занятия уменьшит пропуски из-за пересечения расписания. В согласованном будущем пилоте предложить два временных слота, заранее определить период наблюдения и сравнивать долю посещений и указанную причину «другое занятие». Записать фактический выбор слота и ограничения сравнения; без случайного распределения не заявлять причинный эффект. Реальный эксперимент не проводился, улучшение не измерено.

## Самопроверка и ограничения

Скрипт проверяет заголовки, пропущенные поля, повтор пары участник/занятие, допустимые статусы и соответствие причины статусу. Пустой CSV отклоняется. Суммы из отчёта воспроизводятся запуском; данные не загружаются из сети. При пустом списке пропусков доли причин равны нулю. Нет статистической оценки эффекта и реальных персональных данных.
