# Кестедегі уақыт қайшылықтарын табу

**Kuskon AI командасының Codex көмегімен дайындалған жасанды демо-материалы.** Ол ойдан шығарылған профильдерге ортақ үлгі ретінде қолданылады. Бұл нақты оқушының авторлық жұмысы да, оның дағдыларының дәлелі де емес.

**Тапсырма:** бір күндік кестедегі уақыты қабаттасатын сабақтардың барлық жұбын табу. Код — `schedule.py`; сыртқы кітапханалар мен желі қажет емес.

```bash
python demo_evidence/schedule.py
```

Команда қате кіріс деректерін тексеруді қоса алғанда **9 тестті** іске қосады. Функцияны пайдалану мысалы (бастапқы атаулар сақталған):

```python
from demo_evidence.schedule import find_conflicts

print(find_conflicts([
    ("Python", "09:00", "10:00"),
    ("Дизайн", "09:30", "10:30"),
    ("Математика", "10:30", "11:30"),
]))
# [('Python', 'Дизайн')]
```

## Шешім

`HH:MM` форматындағы уақыт күн басынан өткен минутқа айналдырылады. Әр жұп үшін `max(басталу уақыты) < min(аяқталу уақыты)` шарты тексеріледі. Аралықтар **жартылай ашық**: `[басталуы, аяқталуы)`. Сондықтан 10:00-де аяқталатын сабақ дәл 10:00-де басталатын сабақпен қабаттаспайды. Бірінің ішінде бірі орналасқан және уақыты бірдей әртүрлі сабақтардың аралықтары қайшылық туғызады.

| Тексеру | Күтілетін нәтиже |
|---|---|
| 09:00–10:00 және 09:30–10:30 | Бір қайшылықты жұп |
| 09:00–10:00 және 10:00–11:00 | Қайшылық жоқ |
| Қабаттаспайтын сабақтар кері ретпен берілген | Қайшылық жоқ |
| Уақыты бірдей, атауы әртүрлі екі сабақ | Бір қайшылықты жұп |
| Бір сабақ екіншісінің ішінде толық орналасқан | Бір қайшылықты жұп |
| Өзара қабаттасатын үш сабақ | Үш жұптың бәрі |
| Бос кесте немесе бір сабақ | Бос тізім |
| Қате формат, жарамсыз уақыт, нөлдік ұзақтық, келесі тәулікке өту | `ValueError` |
| Қайталанатын атау, бос атау немесе қате кіріс құрылымы | `ValueError` |

## Шектеулер және рефлексия

Алгоритм ең көбі `n × (n − 1) / 2` салыстыру жасайды: уақыт күрделілігі — `O(n²)`, нәтижелерге қажет жад — ең көбі `O(n²)`. Шағын оқу кестесі үшін бұл түсінікті шешім. Сабақ атаулары бірегей болуы керек; рұқсат етілген уақыт — 00:00–23:59, басталуы аяқталуынан ерте болуы тиіс. Күндер, уақыт белдеулері, түн ортасынан өту, кабинеттер мен мұғалімдер ескерілмейді: барлық сабақ бір топтың ресурстары ретінде қарастырылады. Келесі қадам — нақты ресурстарды және бірнеше күнге арналған тесттерді қосу.

Тексерулер автоматтандырылған, пайдаланушылармен зерттеу жүргізілген жоқ. Қолданбада бір ортақ материалдың әртүрлі жасанды бағалары болуы мүмкін: олар нақты оқушылардың нәтижесін емес, жұмыс паспортының жұмыс істеуін көрсетеді.
