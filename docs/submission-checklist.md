- [x] Публичный URL открывается без входа в аккаунт разработчика; проверены новые кабинеты вуза, родителя и школы.
- [x] Работают отправка работы, оценка, паспорт, согласия, поиск и ответ на приглашение.
- [x] Добавлены личный черновик с отчётом самооценки, явная отправка копии, доработка, защита и история снимков.
- [x] Паспорт различает результат и понимание; свидетельства, проверяющий и ограничения видны отдельно.
- [x] Добавлены четыре типа покупателей: компания, вуз, агентство и фонд; задания, проверки, каталог и приглашения сохраняют права владельца.
- [x] Добавлены школа и организатор: собственные списки, запись с основанием, решение школьника и отзыв источником. Запись не названа независимой сертификацией.
- [x] Родитель связан только с отдельным деморебёнком и управляет своим согласием; личные проекты не показываются родителю. Школьник не меняет согласие связанного представителя.
- [x] Для покупательского каталога по-прежнему нужны принятая работа и оба согласия. Принятие записи источника не обходит эти условия.
- [x] Шкала соответствует коду: веса 40/35/25, оценки 0–4, порог 70 и каждый критерий не ниже 2.
- [x] Полный прогон актуальной редакции: 123 теста прошли; точные результаты и ограничения записаны в TEST_REPORT.txt. Демонстрационные артефакты не изменены с предыдущей проверки.
- [x] Все данные приложения тестовые; демо-роли и демонстрационные согласия явно обозначены.
- [x] В материалах нет выдуманных интервью, оплат, партнёров или рыночных оценок.
- [ ] В README перечислены команда и использованные инструменты, включая Codex.
- [ ] На слайдах приведены источники цифр; интервью и цена имеют фактический статус.
