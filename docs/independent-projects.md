# «Мой проект»: польза школьнику до появления покупателя

Школьник может самостоятельно описать учебный проект, сохранить ссылку на результат, объяснить личный вклад и полученную помощь, пройти самопроверку и скачать текстовый отчёт. Для начала достаточно названия: остальное можно заполнить позже.

**Статус отчёта всегда: «Самооценка. Внешняя проверка не проводилась».** Чекбоксы — собственные утверждения автора; они не дают баллы таланта, не подтверждают авторство и не создают проверенный паспорт.

Проекты доступны только в выбранном демопрофиле школьника и не включаются в поиск покупателей. Переключение демопрофилей не является настоящей авторизацией, поэтому используйте только тестовые данные.

## Отправка на задание

Перед отправкой нужны существующее задание, корректная HTTP/HTTPS-ссылка, описание результата и личного вклада не короче 20 символов каждое. Школьник отдельно подтверждает отправку в интерфейсе. Сервис повторно проверяет владельца проекта и номер версии, затем создаёт отдельную копию в заявке на выбранное задание. Указание commit/tag/версии исходного результата помогает зафиксировать материал, но само по себе не доказывает его неизменность или авторство.

Последующие изменения личного проекта не меняют ранее отправленную копию. Повторная отправка не перезаписывает работу на проверке или принятую работу; новая отправка возможна после запроса доработки. Заказчик задания получает именно явно отправленную копию, а не доступ ко всем личным черновикам школьника.

## API

- `init_projects()` — добавить таблицу после `talent_store.init()`; стартовых личных работ нет.
- `projects(student_id)` — проекты выбранного школьника.
- `save_project(...)` — создать черновик или сохранить изменение с `expected_version`.
- `completeness(project)` — список полей, недостающих для отправки; не рейтинг.
- `project_report(project)` — Markdown с самоотчётом; поля внешней оценки игнорируются.
- `transfer_project(project_id, student_id, challenge_id, expected_version)` — атомарно отправить копию через `talent_store.submit_work`.

Валидация, ограничения доступа в демо, устаревшие версии, независимость копии и отсутствие внешней верификации проверяются в `tests/test_personal_projects.py`.
