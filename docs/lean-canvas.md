# Lean Canvas · TaskUp Talent

Версия для проверки гипотез, 12.11.2026. Ниже — проект бизнес-модели; оплат, интервью и партнёрств пока не подтверждено.

| Блок | Гипотеза первого пилота |
|---|---|
| Проблема | Координатор корпоративной образовательной/CSR-программы не может быстро понять, что школьник действительно умеет, по набору грамот. Выбранный разрыв — доверие. Частоту и стоимость проблемы проверяем интервью. |
| Пользователь | Школьники 9–11 классов, примерно 14–17 лет, из Актюбинской области, интересующиеся IT. Хотят получить полезную обратную связь и показать свою работу при отборе в образовательную программу. |
| Покупатель | Координатор одной корпоративной образовательной/CSR-программы с задачей набрать школьников. Его бюджет, полномочия и срок закупки ещё нужно установить. |
| Ранние участники | Один координатор с открытым набором; один школьный IT-клуб и один организатор регионального мероприятия как предполагаемые каналы. Договорённостей нет. |
| Предложение | «Отберите школьников по выполненной работе и понятной оценке». Покупатель видит артефакт, критерии и решение проверяющего; школьник получает паспорт работы и обратную связь. |
| Решение | Мини-задание → результат и рефлексия → экспертная оценка по фиксированной шкале → паспорт → добровольная видимость → приглашение внутри приложения. |
| Каналы | Прямые интервью координаторов; обсуждение пилота с руководителем одного IT-клуба и организатором одного мероприятия. Плановая воронка — в [плане запуска](launch-plan.md). |
| Доход | Непроверенная цена 100 000 ₸ за 30 дней одной кампании: рабочее пространство, процесс оценки, список подходящих кандидатов. Школьнику бесплатно. Объём проверок и труд эксперта согласуются до предложения. |
| Расходы | Время проверяющих, привлечение, поддержка, хостинг, подготовка безопасного пилота. Экономика не рассчитана без фактического времени проверки; прибыль не заявляется. |
| Метрики | Из регистрации в отправку работы; доля работ с завершённой проверкой; медианное время проверки; согласие на показ; приглашения и ответы; оплаченный пилот и повторный заказ. |
| Преимущество | Предполагаемая ценность — единый путь от задания до доказательства навыка и приглашения. Защищённого конкурентного преимущества пока нет; его могут создать партнёрские каналы и качество экспертной процедуры. |
| Альтернативы | Ручной просмотр грамот и ссылок; олимпиады и их результаты; GitHub-портфолио; собственный конкурс компании. Сравнение и источники — [здесь](sources-market.md). |

**Что проверяем первым:** покупатель тратит достаточно времени на ручной отбор; работа по критериям полезнее привычного пакета документов; школьник готов выполнить мини-задание; координатор готов оплатить пилот. Отрицательные ответы меняют предложение, а не скрываются.
